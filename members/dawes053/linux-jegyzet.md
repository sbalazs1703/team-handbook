# Mi a WSL2?
Natív Linux környezet windowsra.
Példa: Én most telepítettem egy Ubuntut a WMware-re virtuálisan xD ahelyett hogy csak natívan windowson belül kreáltam volna egy környezetet a WSL2-vel.
# pwd
Mit csinál: Printeli a könyvtár elérési útját.
Példa: pwd → /home/...

# ls
Mit csinál: Ki listázza az adott mappákat (röviden)
Példa: Itt vagyok: C:/Users/név/Documents/GitHub -> ha ide írok egy ls -t akkor kilistázza a GitHub mappa mappáit.

# cd
Mit csinál: Change directory. Mappát vált.
Példa: cd/Documents/GitHub/team-handbook  így az aktuális könyvtáram a team-handbook.
